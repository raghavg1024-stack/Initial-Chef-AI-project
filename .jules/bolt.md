## 2026-09-16 - Streamlit Caching String Normalization with hash_funcs
**Learning:** Streamlit's `@st.cache_data` hashes input arguments directly before executing the decorated function. Even if a function normalizes string parameters (e.g. `s.strip()`), variations in argument whitespace or formatting still produce different cache keys and result in cache misses. Returning string from `hash_funcs` causes infinite recursion in Streamlit's hashing engine, but returning UTF-8 encoded bytes from `hash_funcs` safely normalizes inputs.
**Action:** Use `hash_funcs={str: lambda s: " ".join(s.strip().split()).encode('utf-8')}` when decorating string-query functions with `@st.cache_data` to ensure whitespace variations hit the cache without re-invoking LLMs or expensive backend calls.
